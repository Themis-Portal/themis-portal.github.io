業務委託契約書

株式会社Themis（以下「甲」という。）と＿＿＿＿＿＿＿＿（以下「乙」という。）は、携帯電話販売業務、イベント販売業務その他付随業務に関し、以下のとおり業務委託基本契約（以下「本契約」という。）を締結する。

第1条（目的）

本契約は、甲が乙に委託し、乙がこれを受託する携帯電話販売業務、通信関連サービス販売業務、イベント販売業務その他これらに付随又は関連する業務に関する基本的事項を定めることにより、甲乙間の権利義務関係を明確化し、本業務の適正かつ円滑な遂行を図ることを目的とする。

第2条（委託業務）

1. 甲は乙に対し、次の各号に定める業務（以下「本業務」という。）を委託し、乙はこれを受託するものとする。

（1）携帯電話、スマートフォン、通信回線、インターネット接続サービスその他通信関連商品の販売促進業務

（2）イベント販売、催事運営業務及び営業支援業務

（3）ショッピングモール、家電量販店、商業施設その他の施設における接客、販売及び顧客対応業務

（4）市場調査、販売実績報告その他前各号に付随し又は関連する業務

（5）前各号に付帯し、甲が別途指示する業務

2. 本業務の具体的内容、履行場所、履行期間、業務時間、報酬額、支払条件その他必要事項については、甲乙間で別途締結する個別契約書、注文書、発注書、電子メール、LINEその他電磁的方法による記録（以下総称して「個別契約」という。）において定めるものとする。

3. 個別契約と本契約の内容が抵触する場合には、個別契約の定めを優先して適用するものとする。

4. 乙は、本業務を善良なる管理者の注意をもって誠実に遂行するものとする。

第3条（独立事業者性）

1. 甲乙は、本契約が業務委託契約であり、甲乙間に雇用契約、労働契約、労働者派遣契約その他これらに類する法律関係を生じさせるものではないことを相互に確認する。

2. 乙は、自己の裁量及び責任において本業務を遂行するものとし、本業務の遂行方法、労働時間、人員配置その他業務運営に関する事項について甲から直接の指揮命令を受けないものとする。

3. 乙は、本業務遂行に必要な人員、設備、車両、通信機器その他一切の物品を自己の責任と費用負担において準備するものとする。

4. 乙は、本契約に基づく報酬について自らの責任において納税その他法令上必要な手続を行うものとする。

第4条（業務責任者）

1. 乙は、本業務遂行に関する責任者を選任し、その氏名及び連絡先を甲に通知するものとする。

2. 業務責任者に変更が生じた場合、乙は遅滞なく甲に対し書面又は電磁的方法により通知しなければならない。

3. 本業務に従事する者に対する指揮監督、勤怠管理、教育指導、安全衛生管理その他労務管理上必要な事項については、乙が自己の責任と費用負担において実施するものとする。

4. 乙又は乙の従事者の行為により甲又は第三者に損害が生じた場合、乙はその一切の責任を負うものとする。

第5条（再委託）

1. 乙は、甲の事前の書面による承諾を得ることなく、本業務の全部又は一部を第三者に再委託し、又はその履行を第三者に行わせてはならない。

2. 甲が再委託を承諾した場合であっても、乙は再委託先に本契約と同等以上の義務を負わせるものとする。

3. 再委託先の行為又は不作為により甲又は第三者に損害が生じた場合、乙は自己の行為と同一の責任を負うものとする。

第6条（報酬及び支払方法）

1. 本業務に対する報酬額は個別契約において定めるものとする。

2. 乙は、毎月末日を締日として当月分の報酬を集計し、翌月5営業日以内に甲へ請求書を提出するものとする。

3. 甲は、適法かつ有効な請求書を受領した日の属する月の翌月末日までに、乙の指定する金融機関口座へ振込送金の方法により支払うものとする。

4. 振込手数料は甲の負担とする。

5. 甲は、乙に対する債権を有する場合、乙に対して支払うべき報酬その他金員と対当額において相殺することができるものとする。

6. 乙は、甲の事前の書面による承諾なく、本契約に基づく債権を第三者へ譲渡し、担保に供し、又はその他の処分を行ってはならない。

第7条（費用負担）

1. 本業務遂行に要する交通費、通信費、宿泊費、備品代その他一切の費用は、個別契約に別段の定めがある場合を除き、乙の負担とする。

2. 甲が事前に承認した費用については、乙は領収書その他支出を証明する資料を添付のうえ甲へ請求するものとする。

第8条（秘密保持）

1. 乙は、本契約又は本業務に関連して知り得た甲、甲の取引先又は顧客に関する営業上、技術上、経営上その他一切の非公開情報（以下「秘密情報」という。）を厳重に管理し、甲の事前の書面による承諾なく第三者へ開示、漏洩又は提供してはならない。

2. 乙は、秘密情報を本業務遂行以外の目的に利用してはならない。

3. 乙は、秘密情報を知る必要のある者以外に開示してはならず、当該者に対して本契約と同等の秘密保持義務を負わせるものとする。

4. 乙は、本契約終了時又は甲から請求を受けた場合、秘密情報及びその複製物を直ちに返還又は廃棄しなければならない。

5. 本条に定める義務は、本契約終了後5年間存続するものとする。

第9条（個人情報保護）

1. 乙は、個人情報の保護に関する法律その他関連法令及びガイドラインを遵守し、個人情報を適切に管理するものとする。

2. 乙は、本業務遂行上知り得た個人情報を本業務遂行以外の目的に使用してはならない。

3. 乙は、個人情報の漏洩、滅失、毀損その他事故が発生し、又はそのおそれが生じた場合には、直ちに甲へ報告するとともに、甲の指示に従い必要な措置を講じなければならない。

4. 乙の責に帰すべき事由により個人情報漏洩等が発生し、甲又は第三者に損害が生じた場合、乙はその一切の損害（合理的な弁護士費用を含む。）を賠償する責任を負うものとする。

第10条（顧客との直接取引の禁止）

1. 乙は、本契約期間中及び本契約終了後1年間、甲の事前の書面による承諾なく、本業務を通じて知り得た甲の顧客、取引先又は見込顧客に対し、直接又は間接を問わず営業活動、勧誘、契約締結その他取引行為を行ってはならない。

2. 乙は、第三者を介する方法その他名目の如何を問わず、前項の規定を潜脱する行為を行ってはならない。

3. 乙が本条に違反した場合、乙は違約金として金500,000円を甲に支払うものとする。

4. 前項の違約金は損害賠償額の予定ではなく、甲は当該違約金とは別に、当該違反行為により被った損害の賠償を請求することができるものとする。

5. 本条の規定は、本契約終了後も有効に存続するものとする。

第11条（人材及び取引先の引抜き禁止）

1. 甲及び乙は、本契約期間中及び本契約終了後1年間、相手方の役員、従業員、業務委託先、協力会社、取引先その他これらに準ずる関係者に対し、自己又は第三者のために、転職、転籍、業務委託契約の締結その他これらに類する行為を勧誘し、又は引き抜きを行ってはならない。

2. 前項の規定には、直接的な勧誘のみならず、第三者を介した勧誘、SNSその他の通信手段を利用した勧誘その他実質的に引抜きに該当する一切の行為を含むものとする。

3. 前二項の規定に違反した場合、違反当事者は、違約金として1件につき金1,000,000円を相手方に支払うものとする。

4. 前項の違約金は損害賠償額の予定ではなく、相手方は当該違約金とは別に実際に被った損害の賠償を請求することができるものとする。

第12条（競業避止義務）

1. 乙は、本契約期間中及び本契約終了後1年間、甲の営業秘密、顧客情報、取引条件その他本業務を通じて知り得た情報を利用して、甲の既存顧客又は見込顧客に対し、甲と競合する事業又は業務に関する営業活動を行ってはならない。

2. 乙は、第三者を利用する方法その他名目の如何を問わず、前項の規定を潜脱する行為を行ってはならない。

3. 乙が本条に違反した場合、甲は乙に対し、当該違反行為の差止め及び損害賠償を請求することができるものとする。

第13条（業務の履行及びキャンセル）

1. 乙は、個別契約に基づき受託した業務を善良なる管理者の注意をもって誠実に履行しなければならない。

2. 乙は、本業務の履行が困難となり、又はそのおそれが生じた場合には、直ちに甲へ報告し、その指示に従うものとする。

3. 乙の都合により業務開始日の前日又は当日に業務をキャンセルする場合、乙は自己の責任と負担において代替要員の確保に最大限努めるものとする。

4. 乙による無断欠勤、無断キャンセル、著しい遅刻その他契約不履行により甲又は第三者に損害が生じた場合、乙はその一切の損害を賠償する責任を負うものとする。

5. 前項の損害には、代替要員確保費用、取引先対応費用、逸失利益その他合理的に発生した費用を含むものとする。

第14条（損害賠償）

1. 甲又は乙は、本契約又は個別契約に違反し、相手方に損害を与えた場合、その通常かつ直接の損害を賠償する責任を負うものとする。

2. 前項に基づく損害賠償額の総額は、損害発生時から遡って過去12か月間に甲が乙へ支払った報酬総額を上限とする。

3. 前項の規定は、次の各号のいずれかに該当する場合には適用しない。

（1）故意又は重過失による場合

（2）秘密保持義務違反

（3）個人情報保護義務違反

（4）第10条違反

（5）第11条違反

（6）第12条違反

4. 本条に基づく損害には、合理的な弁護士費用を含むものとする。

第15条（反社会的勢力の排除）

1. 甲及び乙は、現在及び将来にわたり、自ら並びにその役員、従業員及び実質的支配者が反社会的勢力に該当しないことを表明し保証する。

2. 甲及び乙は、自ら又は第三者を利用して、暴力的要求行為、脅迫的言動、風説の流布、偽計又は威力を用いる行為その他これらに準ずる行為を行わないことを保証する。

3. 相手方が前二項に違反した場合、他方当事者は何らの催告を要することなく直ちに本契約及び個別契約の全部又は一部を解除することができる。

4. 前項による解除により損害が生じた場合であっても、解除した当事者は何らの責任を負わないものとする。

第16条（不可抗力）

1. 天災地変、地震、津波、台風、感染症の流行、戦争、暴動、テロ行為、法令の制定又は改廃、行政機関による命令その他当事者の合理的支配を超える事由（以下「不可抗力事由」という。）により本契約上の義務を履行できない場合、当該当事者はその責任を負わないものとする。

2. 前項の場合、当該当事者は速やかに相手方へ通知し、損害の拡大防止に努めるものとする。

第17条（契約期間）

1. 本契約の有効期間は、本契約締結日から1年間とする。

2. 契約期間満了日の30日前までに、甲又は乙のいずれからも書面又は電磁的方法による更新拒絶の通知がなされない場合、本契約は同一条件にてさらに1年間更新されるものとし、以後も同様とする。

第18条（任意解約）

1. 甲又は乙は、相手方に対し30日前までに書面又は電磁的方法により通知することにより、本契約を将来に向かって解約することができる。

2. 前項による解約は、解約日以前に成立した個別契約の効力に影響を及ぼさないものとする。

第19条（解除）

1. 甲又は乙は、相手方が次の各号の一に該当した場合、何らの催告を要することなく直ちに本契約及び個別契約の全部又は一部を解除することができる。

（1）本契約又は個別契約に重大な違反をしたとき

（2）支払停止又は支払不能となったとき

（3）差押え、仮差押え、仮処分、強制執行又は競売の申立てを受けたとき

（4）破産手続開始、民事再生手続開始、会社更生手続開始又は特別清算開始の申立てがあったとき

（5）租税公課の滞納処分を受けたとき

（6）信用状態が著しく悪化したと認められるとき

（7）反社会的勢力との関与が判明したとき

（8）その他本契約を継続し難い重大な事由が生じたとき

2. 前項による解除により損害が生じた場合、解除した当事者は相手方に対して損害賠償を請求することができる。

第20条（協議事項）

本契約に定めのない事項又は本契約の各条項の解釈について疑義が生じた場合、甲乙は信義誠実の原則に従い、協議の上これを解決するものとする。

第21条（合意管轄及び準拠法）

1. 本契約及び個別契約の成立、効力、履行及び解釈については、日本法を準拠法とする。

2. 本契約又は個別契約に関して生じる一切の紛争については、東京地方裁判所を第一審の専属的合意管轄裁判所とする。

第22条（権利義務の譲渡禁止）

1. 甲及び乙は、相手方の事前の書面による承諾なく、本契約又は個別契約上の地位並びにこれらに基づく権利又は義務の全部若しくは一部を第三者に譲渡し、承継させ、担保に供し、その他一切の処分をしてはならない。

2. 前項に違反してなされた行為は、相手方に対する関係において無効とする。

第23条（契約終了後の措置）

1. 本契約が終了した場合、乙は、甲から貸与又は提供を受けた資料、名刺、制服、端末機器、記録媒体、営業資料、顧客情報その他甲に帰属する一切の物品及びデータを、直ちに甲へ返還し、又は甲の指示に従い廃棄若しくは削除しなければならない。

2. 乙は、前項に基づく廃棄又は削除を行った場合、甲から求められたときは、その事実を証明する書面又は電磁的方法による報告を行うものとする。
